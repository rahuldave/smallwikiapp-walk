## End to end, and CI

- the two tests marked **e2e** ask the real Wikipedia, with `just test -m e2e`
- every other run leaves them out
- `pyproject.toml` now says `requires-python = ">=3.11"`, so any Python from 3.11 on works. 3.11 is the oldest Python that still gets security fixes

**CI**, continuous integration: GitHub runs the tests on every push to main and every pull request:

| | 3.11 | 3.12 | 3.13 | 3.14 |
|---|---|---|---|---|
| Linux | tests | tests | tests | tests |
| macOS | tests | tests | tests | tests |
| Windows | tests | tests | tests | tests |

One more job runs `just check` once, on Linux.
